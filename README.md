# Askly

Askly — это интерактивный справочник вопросов с быстрым поиском по ключевым словам. Проект представляет собой простой статический веб-сайт на HTML, CSS и JavaScript, который помогает быстро находить нужные темы и просматривать готовые вопросы без лишних переходов.

## Что умеет проект

- Поиск вопросов по ключевым словам
- Раскрытие карточек с вопросами и вариантами ответов
- Поддержку нескольких типов контента в базе вопросов
- Удобный интерфейс для быстрого просмотра информации
- Быстрые ссылки на контакты и сервисы автора

## Структура проекта

- index.html — основная страница сайта
- style.css — стили интерфейса
- script.js — логика поиска, отображения вопросов и модального окна
- questions.json — база данных вопросов
- шаблон.txt — шаблон или пример структуры данных

## Как запустить

Так как это статический проект, его можно открыть напрямую в браузере:

1. Откройте файл index.html
2. Или запустите локальный сервер, например:

```bash
python -m http.server 8000
```

После этого откройте в браузере адрес:

```text
http://localhost:8000
```
